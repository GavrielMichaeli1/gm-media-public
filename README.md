# G.M Media

**Personal Media Library & Streaming System**  
*Private, non-commercial development project*

G.M Media is a personal media server and library interface developed for private use. It is designed to organize and play legally held media from a user's own collection through a consistent desktop and browser experience.

## Project overview

The application is designed to support:

- Movies, TV series, episodes, music, podcasts, and filmed stage musicals
- Organized media libraries with posters, artwork, descriptions, and cast information
- Playback, subtitles, audio selection, watch progress, and personal profiles
- Optional metadata and artwork integrations, including TMDB, TheTVDB, and Fanart.tv

## Fanart.tv integration

G.M Media uses Fanart.tv artwork, where available, to enhance the presentation of locally catalogued movies and TV series, including posters, backdrops, and logos. Artwork is requested for identified titles and may be cached locally. The integration is intended for personal, non-commercial use and credits Fanart.tv as the source of its artwork.

**Artwork provided by [Fanart.tv](https://fanart.tv/).**
